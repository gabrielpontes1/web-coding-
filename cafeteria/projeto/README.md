# Café Abreu

Site institucional responsivo desenvolvido para a cafeteria fictícia
**Café Abreu**, localizada em Abreu e Lima - PE.

## Sobre o projeto

O projeto foi desenvolvido como atividade de Front-End utilizando HTML5
e CSS3. O objetivo é apresentar a cafeteria, seus produtos, depoimentos,
informações de contato e um espaço para sugestões dos clientes.

O site foi pensado para funcionar em diferentes tamanhos de tela,
utilizando Flexbox, unidades relativas e Media Queries.

## Público-alvo

-   Moradores de Abreu e Lima e região
-   Trabalhadores da região
-   Estudantes
-   Turistas
-   Pessoas que procuram um espaço para café, encontros ou trabalho
    remoto

## Estrutura do site

O site utiliza uma estrutura de página única com navegação por âncoras:

-   **Sobre** --- apresentação da cafeteria e sua proposta
-   **Cardápio** --- bebidas e comidas disponíveis
-   **Depoimentos** --- avaliações de clientes
-   **Contato** --- endereço, telefone e e-mail
-   **Sugestões** --- formulário para envio de dados e comentários

## Responsividade

O CSS utiliza Media Queries para adaptar o layout a telas menores.
Também são utilizadas propriedades como `width: 100%`, `max-width`,
Flexbox e unidades relativas para evitar que os elementos ultrapassem o
espaço disponível.

## Identidade visual

A identidade visual utiliza tons terrosos e relacionados ao café, como:

As fontes utilizadas incluem Poppins e Playfair Display.
